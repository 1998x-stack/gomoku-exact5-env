# GomokuExact5-v0：恰五连五子棋 Gymnasium 环境

本说明面向研究与工程落地，系统阐述“恰五连（Exact-5）”五子棋环境的安装、调用、观测空间、动作与奖励语义以及终局判定。该环境以“必须恰好五连才胜，六连及以上不算胜”为核心规则，配合确定性的裁判逻辑与可屏蔽的动作掩码，便于在自博弈、课程式训练与对抗评测中保持可复现实验。文档还将解释非法手与和棋的处理方式、ANSI 文本渲染与随机种子策略，并在最后讨论测试与扩展建议。通过这些说明，你可以将环境快速集成进现有的 RL 训练脚本，同时确保接口稳定、行为可预期、日志便于追溯。

## 使用
```python
import gymnasium as gym
import numpy as np
import gomoku_exact5

env = gym.make("GomokuExact5-v0", board_size=15)
obs, info = env.reset(seed=42)

done = False
while not done:
    mask = obs["action_mask"]
    action = np.random.choice(np.flatnonzero(mask))
    obs, reward, terminated, truncated, info = env.step(action)
    done = terminated or truncated

print("Result:", reward, info)
env.close()
```

## 背景与总体设计

环境专注于 Exact-5 规则系，这一选择在表达力与可验证性之间取得良好平衡，对于算法分析尤为友好。Exact-5 要求在水平、垂直或两条对角线方向上形成连续且恰为五子的连线，因而排除了自由五子中“长连即胜”的不确定性与裁判歧义。对强化学习而言，明确的胜负条件与稀疏但干净的奖励结构，让信用分配与对抗评价更加直观可解释。与此同时，观测结构保持稳定，动作空间是离散且配套可行动作掩码，充分降低了集成成本。整体设计力求“少即是多”，用最小规则集支撑扎实的研究实践。

### Exact-5 与其他变体的关系

与自由五子相比，Exact-5 不把六连及以上视为胜利；与连珠相比，它不引入三三或四四禁手的复杂裁判，而是仅围绕“恰五连”这一核心事实判定输赢。实现层面，落子后只需在四个主方向统计连续同色子的长度，并在 run 等于五时进一步检查两端是否仍能延伸为己子，若能延伸则说明其实是嵌入于更长连中的“假五”，不能判胜。这套定义既贴近人类直觉，也便于单元测试覆盖各种边界场景。由于每步仅计算四条射线，复杂度在更大棋盘上也能保持可控。

## 安装与入门

项目采用标准的 `pyproject.toml` 与 `setup.cfg`，可通过可编辑安装在本地快速迭代与调试。安装完成后，只需在代码中通过 `gym.make("GomokuExact5-v0", board_size=15)` 进行构造，即可获得一个可重置、可步进、可渲染的环境实例。若希望免显式导入模块，也可以使用 Gymnasium 支持的“模块限定 ID”写法以触发自动导入，从而在更复杂的工程目录结构下保持接口简洁。完成这一过程后，你应当能够以固定随机种子重置环境，运行随机或启发式策略至终局，并在控制台查看渲染与诊断信息。这样的烟囱测试同时也适合作为 CI 的健康检查。

### 可编辑安装与环境创建

开发阶段推荐使用可编辑安装，使得源代码修改后可以立即复用，无需反复构建 wheel。环境构造时可以传入棋盘尺寸、非法手策略与渲染模式等参数，以满足不同的研究场景。环境返回的观测包含棋盘矩阵、走子方标记以及扁平化的动作掩码，后者在策略采样与网络前向时都能高效屏蔽无效动作。为便于快速自检，可以编写一个基于掩码的随机对局脚本，直至胜、负或和，并输出终局原因与最后一步坐标。这个脚本同时也能帮助你校验种子与确定性。

## 观测、动作、奖励与终局

观测采用显式的字典结构，强调可读性与前向兼容性。棋盘以 `int8` 存储，零为空点，一为黑子，二为白子；走子方以离散变量表示，从而避免歧义和额外编码负担。动作掩码是长度为 `board_size * board_size` 的二元向量，在空点处为一，便于在策略侧进行带掩码的采样与损失构造。环境在返回观测时复制棋盘数据，以确保不可变契约，这对向量化封装与经验回放都更稳妥。这样设计能最大限度地减少“隐式状态”带来的误解，并提升与外部工具链的兼容性。

### 动作含义与掩码行为

动作以行优先顺序映射到棋盘坐标，通过整除与取模即可实现双向映射，这种确定性映射简单高效。默认情况下，代理可以利用掩码天然避开非法点；若仍然选择被占用位置，则依据策略配置触发终止或继续。在严格模式下，环境以负奖励直接终止，以便快速惩戒错误探索；在宽松模式下，环境给出惩罚但不修改棋盘，从而支持课程学习或鲁棒性实验。无论何种模式，步进结果都会携带是否非法的标志，方便在日志与可视化中进行统计与溯源。借助这些信号，研究者可以更准确地理解策略的行为边界。

### 奖励结构与终局条件

为保持任务纯粹，环境采用极简的奖励设计：成五者得分为正，对手视角等价为负，和棋为零。终局在出现恰五连的落点当步判定，或在棋盘填满且最后一步未形成恰五连时判和。默认不使用截断，因而回合完全由博弈动态决定，除非外部封装引入时间限制。这种设计令学习曲线更易解释，避免了混入与任务无关的激励。对于需要细粒度信号的研究，可以在外层封装中添加辅助奖励，而无需修改环境核心判定。

## 恰五连裁判细节

裁判器在每步合法落子后沿四个方向统计相邻同色子的数量，将左右或两端相加再加上当前落子得到 run 值。若 run 等于五，则进入端点检查，确认 run 两端紧邻是否仍为己子，若是则说明属于长连嵌套，不应判胜。该方法自然处理了边界成为阻断端的情形，因此在棋盘边缘也不会发生误判。由于每次只需访问有限数量的格点，计算开销小且与棋盘大小线性相关的常数很小。配合单元测试中的多样化排列，这套判定可以在回归中稳定保障语义不漂移。

### 长连的非胜属性与策略影响

六连及以上的长连在本环境中是允许落子但不构成胜利的，这与自由五子的常识不同。策略因此需要学习在长度四向五的精确收官，避免无意义延长，进而带来更强的局部形势理解。渲染与日志会直观反映为何对局在长连后仍然继续，帮助定位模型在规则理解上的偏差。研究者可以据此设计更有针对性的课程，引导策略先识别潜在恰五点，再组织出高质量的收官路径。这种行为差异往往在训练早期即可观察，从而提供快速反馈。

### 和棋、非法手与可配置策略

当棋盘最后一个空点被占据且该步未形成恰五连时，对局以和棋终止并返回零奖励。非法手的默认策略是终止并给予负奖励，以抑制退化探索；在研究容错或噪声控制时，也可以改为惩罚后继续，从而观察恢复能力。无论哪种配置，`info` 字段都会包含终止原因、胜者信息与落子坐标，便于统计分析与案例复盘。借助这些统一的诊断接口，可以在不修改环境核心的情况下构建丰富的实验流水线。长期来看，这种分层设计也有助于维持接口稳定性。

## 渲染、随机种子与可复现性

ANSI 文本渲染以索引化棋盘输出局面与走子方，适合在终端与 CI 环境中使用。渲染仅依赖当前观测，因而在不同平台上输出一致，便于进行快照测试与教程展示。对于需要图形化的场景，可以在外层封装更复杂的可视化而不影响核心逻辑或公共接口。我们优先考虑确定性与透明性，而非复杂的图形效果，以保持工具链轻量与可移植。这样的取舍在团队协作与自动化测试中具有显著优势。

### 种子管理与确定性运行

环境遵循 Gymnasium 的种子接口，通过 `reset` 传入种子即可获得可再现的初始状态。由于博弈本身在动作确定时是完全确定性的，种子主要影响外层的随机策略、数据采样与任何用户侧的随机过程。为确保实验复现，建议同时固定环境与策略的种子，并在元数据中记录它们，同时冻结依赖版本。使用相同脚本与相同种子重复运行应当复现轨迹、终止原因与回报，从而使回归测试与对比实验变得可靠。对严肃的研究结论而言，这种确定性至关重要。

## 训练与评测实践

环境兼容常见的强化学习库，接口规范清晰，便于直接接入策略梯度或基于价值的方法。在基线阶段，利用动作掩码即可显著减少无效探索，随后逐步引入更严苛的配置来提升策略稳健性。自博弈是自然的评测协议，可以交替执黑执白并在多个种子上平均结果以降低方差。通过记录终局原因与关键落点，可以分辨策略是在战术上获胜还是依赖对手失误或非法手惩罚。这样的数据能够帮助你更精准地定位模型改进方向。

### 基线与课程设计建议

使用基于掩码的随机策略可以快速验证环境是否按预期终止，并校验和棋比例是否合理。在此基础上，浅层函数逼近就能学会开放四与受限三等局部模式，通常能明显超过随机策略。课程式训练可以从小棋盘开始，以缩短时域与降低探索难度，再平滑扩展至更大棋盘。另一种路径是先用裁判器自动标注静态局面，训练一个评估头去识别恰五机会，再在端到端控制中微调。上述方法往往能显著加快早期收敛并降低训练曲线的方差。

## 测试、诊断与性能

仓库中提供了注册、步进与胜负判定的单元测试，用以防止重构引入的行为漂移。典型测试会布子形成横向恰五并验证六连不胜，同时在满盘无五时判和，从而覆盖最关键的裁判路径。在你的工程中，可加入基于性质的随机化测试，将环境裁判与参考裁判比对，以覆盖更广泛的排列。ANSI 渲染的文本也可以做快照测试，避免格式变化影响日志解析或教程展示。完善的诊断与测试护栏能让你放心地演进内部实现。

### 复杂度与扩展规模

每步仅沿四个方向计数，因而步进开销小且稳定，在更大的棋盘上也具备良好的可扩展性。若需要批量训练，可使用向量化封装在同一进程中并行多个环境，观测轻量且渲染可关闭，不会成为性能瓶颈。内存占用随棋盘维度二次增长，但 `int8` 表示将总体占用控制在较低水平，足以在常见硬件上运行大批量实验。对于更极限的场景，可以外层叠加缓存与并行化策略，而无需更改环境接口。这样的工程弹性使其适合教学与前沿研究双重用途。

## 扩展性与接口稳定

公共 API 暴露了满足主流需求的参数，同时隐藏了易变的内部细节，从而维持对外兼容。你可以自由调整棋盘大小、非法手策略与渲染方式，而无需修改裁判核心或观测结构。若需要更多调试信号，建议通过外层封装计算派生特征并写入 `info`，避免破坏观测的稳定契约。对新增功能应同时在中英文文档中清晰记录，以降低团队协作的沟通成本。坚持这些实践，可以让环境长期保持可维护、可复用与可演化。

### 向后兼容的演进原则

扩展时优先采用“增量不破坏”的方式，避免改变观测键名或数据类型，以免对下游造成断裂。若需要额外的调试信息，优先放入 `info` 而非观测主体，并配套单测覆盖新的诊断字段。保持恰五连语义的严格性与测试完备性，使得旧模型在新版本下不会遭遇无声的行为变化。中英文文档中的参数与行为描述应保持同步更新，以支撑跨团队、跨项目的复用。通过这些措施，环境可以成为更大系统中的稳定基石。
